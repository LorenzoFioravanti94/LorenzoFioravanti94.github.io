# Lorenzo Fioravanti — Portfolio

Personal portfolio of **Lorenzo Fioravanti**, Analytics Engineer based in Barcelona.

🔗 **Live site:** https://LorenzoFioravanti94.github.io

The portfolio is built around one idea: a modern data stack can be entirely open-source —
reproducible, vendor-neutral and cost-efficient — without giving up engineering rigor.

## Tech

- [Astro](https://astro.build) — static site framework
- [Tailwind CSS](https://tailwindcss.com) + [DaisyUI](https://daisyui.com)
- Deployed to GitHub Pages via [`withastro/action`](https://github.com/withastro/action)

## Development

```bash
npm install
npm run dev      # local dev server at http://localhost:4321
npm run build    # production build to ./dist
npm run preview  # preview the production build
```
